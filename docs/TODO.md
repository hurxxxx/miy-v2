# UI/UX 개선 기록

이번 인수 작업에서는 코어 동작을 막는 문제를 수정하고 아래 화면·사용성 개선은 후속 작업으로 남긴다.

사용자 CLI의 우선 개선·인수 대상은 Windows 11 x64이며, PowerShell 5.1/7과 Docker Desktop에서 설치·서버 등록·로그인·앱 생성·로컬 개발·개발 배포·운영 승격 흐름을 검증한다. Windows GUI 설치기 구현과 사용법은 [설치 안내](WINDOWS-INSTALLER.md)에 기록한다. Linux/macOS 사용자용 설치 편의 개선과 추가 인수는 이후 단계에서 진행한다.

- Windows GUI 설치기를 실제 Windows 11 일반 사용자 계정에서 인수한다. 사전 설정·검증용 환경변수가 없는 최초 설치, 사내 HTTP IP, 기존 다른 서버 연결, 브라우저 승인, 재설치·제거를 확인한다. 코드 서명과 조직별 배포 정책 적용은 후속 검토한다.
- HTTP IP에서는 클립보드 API가 제한될 수 있어 설치 명령을 직접 선택·복사하는 안내가 필요하다. 현재 수동 복사 경로를 유지하고 복사 상태 표시를 개선한다.
- 설치 안내에서 기존 활성 연결과 이번 명령의 대상 서버가 다를 때 두 주소와 추가·선택 명령을 더 쉽게 비교하도록 배치한다.
- context 저장 이름 `default`를 미리 정해진 서버 주소로 오해하지 않도록 화면 용어를 검토한다. 실제 서버 주소는 명시적 입력으로만 등록한다.
- 개발 세션 충돌·만료 화면에 세션 소유자, 남은 시간, 중지 후 재실행 절차를 읽기 쉽게 정리한다.
- 개발자 등록 요청과 관리자 승인, 운영 배포 권한 부여의 진행 상태를 연결해서 보여주는 안내를 검토한다.
- 배포 작업의 마지막 표시 단계가 `health_check`여도 앱 상태 검사 이후 서버의 후처리에서 실패할 수 있다. 실제 앱 상태와 작업 실패 위치를 구분해 표시하고, job ID로 진단 기록을 찾는 안내를 개선한다.
- 브라우저 로그인 요청 만료·중복 콜백 시 `unauthorized` JSON 화면에 머무르지 않고, 만료된 요청을 폐기하고 새 로그인을 시작할 수 있는 안내를 제공한다. 2026-10-28 사용자 테스트에서 로그인 시간 초과 안내 후 새로고침·관리자 로그인 시 오류가 표시됐고, 다시 로그인하자 정상 진입했다. 같은 시간대에 Keycloak의 `expired_code`·`already_logged_in`과 이후 관리자 API 200 응답을 확인했다. 오류 요청 ID: `00cb6859-9481-47ac-8341-78b653627a96`.

실제 Windows 인수에서 발견한 추가 항목은 재현 단계와 화면·CLI 위치를 함께 기록한다.
