# 구현 계획 안내

이 문서에 있던 V0~V1 최초 계획은 [보관 원문](archive/IMPLEMENTATION-V0-V1.md)으로 옮겼다. 원래 iframe 없는 동적 UI 요구와 현행 MF/AppRoot는 유지한다. 보관이 요구 폐기를 뜻하지 않으며 당시 세부 지침·검사 결과와 후속 보안 검토를 구분한다.

현재 사내 세 출처 최소 설계·개발 단계 전환·필수/후속 인수는 [APP-BOUNDARIES](APP-BOUNDARIES.md), 상세 권한은 [CORE-PERMISSIONS](CORE-PERMISSIONS.md), 순서·상태는 [PLAN](PLAN.md#다음-우선-작업)을 따른다. V0~V7의 유효한 미완료 요구도 APP-BOUNDARIES 승계표에 있다. 문서 확정은 제품 구현이 아니며 실제 결과는 [구현 이력](IMPLEMENTATION-RESULTS.md)과 releases 기록으로 판단한다.
