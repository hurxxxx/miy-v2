# 앱 경계와 개발·배포 인수

이 문서는 기존 링크를 위한 이동 안내다. 설계·인수 기준과 유효한 미완료 요구를 APP-BOUNDARIES에 통합했으며, 여기에는 별도 기준이나 결과표를 유지하지 않는다.

## 경계 인수

BV-01~14의 필수/후속 구분과 실제 시험 환경은 [통합 인수표](APP-BOUNDARIES.md#경계-인수)를 따른다. 현재는 사내 두 출처 최소 보안이며 독립 반복 BV-13·외부 앱 격리·자동 CA를 선행 조건으로 올리지 않는다.

## 기존 검증의 승계

최초 V0~V7과 기타 미완료 요구는 [승계표](APP-BOUNDARIES.md#기존-검증의-승계)에 있다.

## 증거와 판정

실행 기록·FAIL/NOT_RUN·과거 PASS 처리 기준은 [증거와 판정](APP-BOUNDARIES.md#증거와-판정)을 따른다.

## 배포와 UI 런타임 검사

현재 기준은 [경계 인수](APP-BOUNDARIES.md#경계-인수)의 BV-03~05·09·12다. 당시 통합형 검증은 [보관 원문](archive/VALIDATION-MODULE-FEDERATION.md#배포와-ui-런타임-검사)에 있다.
