## 전체 작업 현황

**앱 개발·실행·배포와 기본 관리 기반은 갖췄다. 다음 기능 작업은 G4 디렉터리 확장과 사용자·그룹 선택기 연결이다.** AI-DO 공통 기능 46개는 조사·분류를 마쳤으며, 추가 이식 구현은 아직 시작하지 않았다. 이 서버는 정식 오픈 전 개발 서버다.

| 상태 | 이 문서에서 뜻하는 것 |
| --- | --- |
| 완료 | 지정한 구현·반영·게시 범위를 끝냄. 전체 제품이나 모든 환경 인수의 완료는 아님 |
| 일부 구현 | 재사용할 기반은 있지만 해당 기능의 완료 조건을 채우지 못함 |
| 진행 중 | 실제 착수한 구현과 진행 근거가 있음. 조사 완료나 일부 기반만으로 표시하지 않음 |
| 미착수 | 설계·대상은 있으나 해당 후속 구현을 시작하지 않음 |
| 검증·반영 대기 | 코드·후보가 있어도 해당 실행·환경·반영 증거가 없음 |
| 결정 대기 | 채택·범위·외부 접속 정책을 정해야 함. 자동으로 필수 기능에 포함하지 않음 |

현재 작업본과 기록에서 **진행 중으로 확인되는 새 기능 구현은 없다.** 아래 일부 구현과 미착수·검증 대기를 분리해서 사용한다. 다른 작업자가 착수하면 이 문서의 해당 행과 구현 근거를 함께 갱신한다.

데이터를 바꾸는 구현·반영은 해당 DB·파일·설정의 백업과 별도 복원 확인을 먼저 한다. 전체 백업 제품·host updater·모든 보안 권장 인수를 기능 개발의 공통 선행 조건으로 올리지 않는다. 업무 앱은 설치별 프레임, 플랫폼은 통합 라우팅·단일 IP HTTPS, 업무 데이터·선택적 공간·ACL은 앱 소유다. 개발 단계의 구 API·CLI·설정 하위 호환은 강제하지 않으며 게시 바이트와 적용된 SQL·데이터는 보존한다.

## 미해결 호환성 관찰

Docker 28 classic image store의 native `docker save`는 image `.Id`의 config digest와 OCI manifest digest가 달라 현재 native export 검사에 실패한다. 해결 PASS로 표시하거나 제품 digest 검증을 완화하지 않는다. containerd image store 범위의 회귀와 생성한 classic archive import는 모든 저장소의 raw native export 지원 증거가 아니다. [회귀 환경과 한계](../scripts/runtime-regression/README.md)를 따른다.
