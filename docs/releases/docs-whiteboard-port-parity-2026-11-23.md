# 문서·화이트보드 AI-DO 포팅 대조

`../ai-do/prod`의 `21f3937e2`와 miy-v2 `3140780`을 대조했다. 두 앱의 첫 이식 기준은 AI-DO `0002af062`다. 그 뒤 원본의 두 앱 모듈에서 기능 변경은 없었다. 서버 라우트·접근 판정·화면·테스트를 문서와 화이트보드로 나누어 확인했다.

| 앱 | 이미 이식된 주요 기능 | 이번에 보완한 기능 |
| --- | --- | --- |
| 문서 | BlockNote, 페이지 트리·정렬, Markdown 가져오기·내보내기, 본문 이미지·첨부, 발표 모드, 사용자 공유, 즐겨찾기·최근. miy 보강인 휴지통·버전 기록·댓글·템플릿 | 허브 페이지 이동과 실패 후 재시도, 페이지 목록에서 메타데이터만 받고 열어 보는 페이지의 본문만 읽기(`APP-02`), 이름 편집 중 한글 입력 조합(`DOC-03`), 공간 삭제와 문서 쓰기 사이의 경합 방지(`DOC-02`), 공개 범위 변경과 복제의 권한 확인(`APP-01`), 포털 링크와 연결 메타데이터 조회 |

연결 데이터는 PMS가 소유한다. `0005_resource_links.sql`은 태스크와 공간의 다중 참조, 리스트의 단일 슬롯을 추가하며 태스크와 공간의 한도는 각각 12개다. 문서와 화이트보드는 현재 사용자가 읽을 수 있는 활성 자원의 ID·제목·공간만 반환한다. 연결을 열거나 추가할 때 양쪽 권한을 다시 확인한다. 열 수 없는 자원의 제목과 주소는 숨기고 PMS 편집자에게 연결을 해제할 수 있는 별도의 ID만 보인다. 같은 환경에 세 앱을 설치해 PMS의 `app:docs:read`·`app:whiteboard:read`와 호출 양쪽의 `platform:directory:read`를 설치 릴리스마다 승인한다. 페이지 본문·보드 장면·공간 권한은 각 앱에 남는다.

## 남은 기능과 설치 인수

- 실시간 공동편집과 커서는 M4 후속이다. AI-DO의 WebSocket·Yjs와 Redis 중계, 문서의 Node 변환을 실제 프레임에서 재연결·권한 회수·동시 저장까지 확인한 뒤 런타임 구성을 정한다. [범용 기능 계획](../COMMON-FEATURES-PLAN.md)
- PMS 연결은 PMS 화면에서 관리한다. 문서 화면에서 태스크를 찾아 연결하는 흐름, PMS에서 보드를 바로 만드는 흐름, 원본의 PMS 공간 배치·대상 필터는 남았다.
- CLI 0.18.0 로컬 미리보기는 앱 백엔드의 앱 간 호출을 지원하지 않아 PMS 연결은 설치 프레임에서 제공한다.
- 문서의 익명 링크·HTML 페이지·회의록, 화이트보드의 익명 링크·웹 임베드·회의와 AI 연동, 화면에서 사용하지 않는 문서 컬렉션 API는 기존 범위 결정에 따라 남겼다. 문서 자동 보존 주기와 허브 서버의 조회 비용은 기존 리뷰의 별도 항목이다. [문서 기록](../../apps/docs/docs/PORTING.md) · [화이트보드 기록](../../apps/whiteboard/docs/PORTING.md)

앱 검사는 호환되는 CLI 0.18.0의 `miy app setup`을 임시 작업본에서 실행한 뒤 진행했다. Docs의 캐시된 CLI 0.17.0 검사는 `invalid_manifest`로 실패했다. 초기 Docs DB 시험은 본문을 읽는 API와 메타데이터만 읽는 API를 구분한 뒤 통과했다. PMS의 API 생성은 처음에 `openapi-typescript` 의존성이 누락됐으며 설치 후에는 `LinkScope` 스키마 등록이 빠져 실패했다. 등록을 추가하고 명세와 타입을 재생성했다. 화이트보드 초기 실행의 응답 필드 검증과 장면 타입 검사 실패는 테스트와 입력 정규화를 고친 뒤 통과했다. 앱 검사의 `storage_recovery_review` 권고와 실제 Storage 경로 인수는 계속 추적한다.

화이트보드의 `pnpm build:preview`와 모의 API를 연결한 Chromium 미리보기에서 편집기 적재, 공간 이름·설명 수정, 공유 후보 조회가 실패한 상태에서 기존 공유 해제, 자체 호스팅 글꼴 응답을 확인했다. 첫 실행에서 공간 선택기에 전달한 접근성 라벨이 렌더링되지 않아 로케이터가 실패했다. 역할로 조회해 재실행했다. 미리보기와 설치용 번들에 글꼴 파일이 각각 234개 들어갔다.

`python3 scripts/test-official-apps.py`는 12건 통과했다. 실제 설치 프레임, 운영에 있는 PMS DB의 `0005` 적용, 공식 릴리스 및 서버 반영은 `NOT_RUN`이다.
