일반 검증 사용자 한 명이 콘솔에서 별개의 기기 연결을 승인했다. 관리자는 두 신규 앱의 등록을 승인했다. 에이전트가 작성한 앱 소스에서 전체 검사·커밋·서버 빌드·dev 배포를 수행했다. 독립 브라우저 검증은 해당 일반 사용자로 실제 dev 앱 프레임을 열고 정확한 릴리스와 HTTP 응답·화면 결과를 확인했다. 두 설치 모두 실행 중, 정상, DB 준비 완료였다. prod 승격과 prod 앱 설치는 이번 검증 범위 밖이다.

## 에이전트 연결과 복구

- Codex는 사용자가 볼 수 있는 메시지에 승인 주소·코드·만료 시간을 전달하고 승인 대기를 시작했다. 프로젝트 생성 후 새 네이티브 MCP 세션에서 `get_cli_help`와 `get_contract` 호출을 확인했다. 검증용 네트워크 격리에서 막힌 포털 TLS 통신은 평가자가 허용했다.
- Claude의 첫 비대화형 실행은 도구 결과에 승인 정보가 나타난 직후 사용자에게 별도 메시지를 보내기 전에 대기를 시작했다. 이때는 평가자가 공개 승인 정보만 전달했다. 안내문을 고친 뒤 별도 작업 폴더·새 대화·미인증 CLI로 재검사했다. 최종 응답의 주소·코드·유효시간을 실제 발급 결과와 대조한 후 사용자가 승인했고, 같은 대화가 원래 loginId로 재개해 로그인 상태와 서버 진단을 확인했다.
- Claude는 새 프로젝트 설정으로 다시 연 네이티브 세션에서 `get_cli_help`와 `get_contract`를 호출했다. 격리된 도구 환경에서 큰 응답을 읽을 수 있도록 평가자가 해당 계약 응답 파일만 읽기 전용으로 연결했다. 두 에이전트가 확인한 실제 `platformBundleVersion`은 0.15.0이다.
- 양쪽 모두 첫 설치 전 `miy app dev`가 디렉터리 조회에서 HTTP 403을 받았다. CLI 0.20.0의 [프리뷰 시작 코드](../../crates/miy/src/preview.rs)는 이 경로를 호출하며 [코어 처리기](../../crates/miy/src/connections.rs)는 dev 설치와 승인된 디렉터리 읽기 권한을 요구한다. 두 계산 앱에는 업무상 이 권한이 필요하지 않다. 로컬 프리뷰는 FAIL이며, 실제 dev 게시 화면에서 동일 업무 동작을 검증했다. 최초 설치의 프리뷰 초기화를 디렉터리 조회에서 분리하는 제품 변경은 후속 작업이다.
- 두 앱의 첫 서버 빌드는 컴파일 전에 `docker_storage_low`로 중단됐다. 운영자가 시험용 컴파일 캐시를 정리하고 이전 테스트가 만든 동일 실행 파일의 중복 저장을 줄인 후, 에이전트가 기존 커밋으로 새 서버 빌드를 제출했다. Docker 여유 공간 기준을 유지했다. 개발 작업본의 Rust 디버그 캐시 보관본과 예전 테스트 실행 파일의 해시·원래 시각 등 복원 정보는 호스트의 비공개 `/srv/miy-prod/evidence/agent-guide-dev.VAod4lxx` 아래에 있다.

## 공개 안내문 변경과 검증 범위

두 앱은 안내문 소스 `f96ba62`에서 시작했다. Claude의 최종 응답을 통한 기기 인증은 `7bfe1ca`에서 별도로 재검증했다. 최종 안내문 `a1adebc`에는 첫 프리뷰 403과 서버 저장 공간 부족 시 재개 절차도 반영했다. 최종 문구로 두 앱을 처음부터 다시 게시하는 시험과 Windows·macOS 실기 검증은 수행하지 않았다.

2026-11-25 03:11 UTC에 공유 코어와 worker에 최종본을 반영했다. 포털·콘솔·dev에서 반환한 안내문과 배포 소스의 SHA-256은 모두 `a25a3c519e32dc2bc52e79333396246048995691d849689077d28433b8c665fd`였다. 안내 경로 관련 테스트 8개가 통과했고, 게시 CLI 0.20.0으로 서로 다른 명령 예시 31개의 구문을 확인했다. 호스트 반영 기록은 `/srv/miy-prod/evidence/agent-guide-dev.VAod4lxx/preview/rollout.json`에 있다.

브라우저 검증을 마치고 임시 일반 계정을 비활성화했다. 해당 계정의 활성 CLI 세션은 0개이며 두 검증 앱은 dev에서 계속 열 수 있다. 최종 확인 기록은 `/srv/miy-prod/evidence/agent-guide-browser.pgDd6ng6/cleanup-verified.json`에 있다.
