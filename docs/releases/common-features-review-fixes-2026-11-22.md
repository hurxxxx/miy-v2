## 남은 작업과 인수

- 실제 설치 앱 프레임, Storage와 디렉터리 전체 경로, 실제 OIDC를 사용한 사용자 전환과 새 검색, 보조 프레임 메모리 측정, 실제 모바일·화면낭독 검사는 `NOT_RUN`이다. 웹 요청이 계속 실패해 앱을 닫았다가 다시 연 뒤의 첨부 복구와 전체 앱 권한 경합도 별도 인수 범위다.
- 공용 UI 2.0.1 게시와 앱 적용, SDK 미리보기와 설치 프레임 CSS 우선순위 차이, 게시 CLI와 현재 소스 CLI가 같은 버전을 표기하는 문제를 릴리스 후보에서 확인해야 한다. 런처 앱별 알림 배지·브라우저 OS 알림과 메신저 실시간 메시지·입력 중 표시는 계획에 남는다.
- 문서(M9)·화이트보드(M11)는 기존 작업본에서 포팅 중이다. 문서의 공간 삭제 후 첨부 회수와 매니저 권한 재판정은 라우터 연결 때 검증한다. M10 대용량 전송과 M13 AI 도구는 각각 기존 설계·계획 단계다.
- 운영 반영, 운영 migration, 공식 릴리스 게시·push는 `NOT_RUN`이다. 새 PMS migration의 격리 검증은 앱의 운영 데이터 적용과 구분한다.
